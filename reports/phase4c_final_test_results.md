**Rule followed throughout:** `scripts/phase4c_final_test_evaluation.py` was run exactly one time. Its printed output is transcribed into this report as-is. No branch of the script reacted to the result, and no second run with different settings was performed after seeing the numbers.

## 13. Error Analysis

**Systematic bias, not random scatter:** of the 35 test predictions, the model **overpredicted 28 times and underpredicted only 7 times** (mean signed error, actual − predicted = **−70.57**, i.e. predictions ran about ₹70.57 too high on average). This is a clear, one-directional bias, not symmetric noise.

**Why, investigated rather than left as an unexplained fact:** the training data used for the final fit (rows [0:140], 2025-03-07 to 2025-08-01) has a target mean of **₹1769.85**, while the test period's (2025-08-02 to 2025-09-06) actual target mean is **₹1711.79** — a **₹58 gap**. The frozen Linear Regression's predictions are still substantially anchored toward the training-period mean (the same mean-reversion mechanism Phase 4A/4B identified in the validation-stage model) — so when the *test* period's actual prices ran somewhat lower than the training period's, that anchoring, which had helped on validation, actively hurt on test by systematically pulling predictions above where prices had actually moved.

**Largest errors, not cherry-picked (top 5 by absolute error):**

| Date | Actual | Predicted | Abs. error | `lag_1` | day_of_week |
|---|---|---|---|---|---|
| 2025-09-05 | 1500.00 | 1804.00 | **304.00** | 1600.00 | Friday |
| 2025-08-03 | 1700.00 | 1923.21 | 223.21 | 1650.00 | Sunday |
| 2025-08-06 | 1600.00 | 1811.16 | 211.16 | 1833.33 | Wednesday |
| 2025-08-31 | 1750.00 | 1942.57 | 192.57 | 1733.33 | Sunday |
| 2025-08-08 | 1662.50 | 1834.75 | 172.25 | 1700.00 | Friday |

**Do errors cluster around large price changes?** The largest error (2025-09-05) does coincide with the actual price falling below its recent `lag_1` level (1600 → 1500, a ₹100 drop) while the model predicted a *rise* to 1804 — the model missed a downward move entirely. Two of the top five errors (08-03, 08-31) fall on Sunday, whose coefficient Phase 4B already flagged as unstable across folds — consistent with, though not conclusive proof of, that earlier caution translating into real test-time error.

**Does the model regress toward the mean?** Yes, visibly: the model's predicted-value range on the test set is [1603.99, 1942.57] (spread ₹338.59), while the actual target range is [1500.00, 1833.33] (spread ₹333.33) — similar spread, but **the predicted range sits systematically above the actual range** (predicted minimum 1603.99 already exceeds the actual minimum 1500.00 by over ₹100), directly visible confirmation of the overprediction bias quantified above.

**No modification was made to the model as a result of this analysis.** This is analysis only, as instructed.

## 14. Practical Interpretation

**In concrete terms:** the frozen model's test MAE of ₹91.06/quintal, against actual test-period prices ranging ₹1500–1833/quintal, is an average error of roughly 5–6% of the price level — not trivial, and, critically, **worse than simply averaging the last three known prices** (moving-average-3's ₹73.17 MAE, roughly 4–5%). A vendor or platform relying on this model's forecast would, on average, be told a higher expected price than what actually materialized, 28 times out of 35 in this test window.

**This does not demonstrate production-ready forecasting capability.** The dataset is Hyderabad **district-level proxy** data (never Bowenpally-specific), spans only about six months, and this test evaluation itself rests on just 35 observations — a single, short, one-time slice of one commodity's price behavior in one season. A different 35-day window, a different season, or genuine mandi-level data could easily produce a different ranking among these three methods; this phase does not claim otherwise. **No causal market understanding is claimed anywhere in this report** — Section 13's explanation (the training-mean/test-mean gap) is a statistical account of *why* the numbers came out this way, not a claim that the model has learned anything about *why* Hyderabad potato prices moved as they did in August–September 2025.

## 15. Limitations

- **35 test observations is a small sample** — a single largest error of ₹304 (Section 13) meaningfully moves the test MAE; a slightly different test window could plausibly change which method ranks best.
- **This is a single train/test split, evaluated once** — by design, per this project's own strict rule, and correctly so, but it means this report cannot distinguish "moving-average-3 is generally better for this series" from "moving-average-3 happened to fit this particular 35-day stretch better."
- **The training-mean/test-mean gap (Section 13) is itself just one 35-day snapshot's worth of evidence** — it explains this test period's overprediction bias but is not a general statement about how often training and test means will diverge in future windows.
- **Tomato was never part of this evaluation** and remains out of scope, unchanged from every prior phase's finding.
- **No further evaluation of this model against any other test window is planned or was performed** — per this phase's own strict rule, the test set is used exactly once, and it has now been used.

## 16. Final Forecasting Verdict

**Selected conclusion: C.**

> "Simple baselines performed as well as or better than the selected ML model on the final test period."

This is chosen strictly from the actual results in Section 10 (moving-average-3's test MAE of 73.17 beats Linear Regression's 91.06, and persistence's 89.76 also edges out Linear Regression) — not forced toward a positive ML conclusion despite the validation-stage result, and not softened. **Linear Regression's validation-stage improvement (Section 11) did not generalize; on this final, single, honest test, the simplest available method — moving-average-3 — was the best performer of the three.**

This is reported as an acceptable, legitimate scientific outcome, consistent with this project's standing discipline (Phase 3A.1 onward: report what the evidence shows, not what would make the strongest headline).
